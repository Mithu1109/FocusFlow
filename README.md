# FocusFlow 🎯

**FocusFlow** is a modern, intelligent study planner and productivity iOS application built with **SwiftUI** and **Core Data**. It helps students and learners stay on track with task planning, deep work Pomodoro sessions, and intelligent productivity insights.

---

## ✨ Features

- **📊 Smart Dashboard**
  - Manage daily study tasks with priorities, subjects, and estimated durations.
  - Seamlessly jump from any task directly into an active focus session.

- **⏱️ Focus Timer (Pomodoro Technique)**
  - Customizable focus and break intervals.
  - Link sessions to specific subjects and tasks to track exact time spent.
  - Background-friendly timer controls and progress visualizations.

- **📈 Progress & AI Insights**
  - Track study streaks, completed focus hours, and task completion rates.
  - Smart recommendations for optimal study durations and subjects needing attention.

- **🎨 Themes & Customization**
  - Light, Dark, and System appearance modes.
  - Local notifications and sound cues for interval transitions.

- **💾 Offline-First Architecture**
  - Persistent local storage powered by Core Data.

---

## 🛠️ Tech Stack

- **Platform:** iOS 16.0+
- **Language:** Swift 5+
- **Frameworks:** SwiftUI, Core Data, Combine, UserNotifications
- **Architecture:** MVVM (Model-View-ViewModel)

---

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mithu1109/FocusFlow.git
   ```

2. **Open in Xcode:**
   ```bash
   cd FocusFlow
   open FocusFlow.xcodeproj
   ```

3. **Run the project:**
   - Select an iOS Simulator or connected iOS device in Xcode.
   - Press `Cmd + R` to build and run.
